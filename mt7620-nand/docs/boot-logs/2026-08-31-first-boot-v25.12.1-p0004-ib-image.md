## What this boot proves

- **patches/0004 (ECC bitflip reporting) behaves exactly as
  designed.** On the first install's boot the corrections appeared
  once, while 0004 reported the aged single-bit flips (page 0 of
  ~2022-written PEBs) and UBI scrubbed — rewrote — the affected
  blocks. This boot has **zero `nfc_ecc_verify` lines**: nothing left
  to correct. "Messages once, then silence," as predicted. (The
  reinstall's volume rewrite + rootfs_data format also refresh EC
  headers, pushing the same direction.) From here, any future
  retention flip is corrected, counted in
  `/sys/class/mtd/*/corrected_bits`, and scrubbed automatically.
- **First IB-assembled image on the device** — kernel and kmods from
  one CI run, userland from official feeds, and the kernel-dependent
  presets actually load on this kernel:
  `WireGuard 1.0.0 loaded` and `batman_adv 2025.4-openwrt-5 loaded`.
  The vermagic design (ALL_KMODS + per-run ImageBuilder) is proven end
  to end on hardware.
- NAND driver probes, all **10 partitions**, exact stock layout.
- `ubi0: good PEBs: 944, bad PEBs: 0, corrupted PEBs: 0`; erase
  counters max/mean **5/2** (healthy, barely-worn flash); UBI image
  sequence number preserved (unchanged since the 2022 stock-era
  install — sysupgrade updates volumes, it does not recreate UBI).
- Both radios up and beaconing: mt76x2e (5 GHz) firmware running,
  rt2800 (2.4 GHz) detected; both `AP-ENABLED`, a station associated

- Preset services running: ttyd on 192.168.1.1:7681, https-dns-proxy
